# Workflow Lab: eight-domain development candidate

The local development candidate covers software engineering, industrial and physical systems, natural science, office work, finance, formal reasoning, cybersecurity and media production. It uses distinct executable workflows and behavioral outcome checks. Read the [eight-domain roadmap](docs/iteration-eight-domains.md), [measured quality review](docs/eight-domain-quality-review.md) and [aggregate experiment scorecard](docs/iteration-quality-scorecard.json).

Local verification: 259 tests in the full suite and three additional targeted tests pass. The feedback prototype completed 64 independently solved WebSocket episodes, eight terminal checks and eight pinned-SDK solved episodes. These establish correct execution, not model learnability or learning gain.

H200 calibration rejects the current collection for training: pooled reward near 0.5 can conceal interface failures, exhausted rollout budgets and unlearnable difficulty. The latest media feedback variant has an initial clean mixed group; a selected-basis math tool produced successful proofs, but science and math still lack observed complete clean mixed groups in the latest screens. No local GRPO gain or new official submission is claimed.

The previously published proxy image is an earlier four-domain candidate. The expanded public image has not been released or anonymously replayed. Its deployment still needs a stable HTTPS controller whose grading source stays private. This branch publishes the protocol client and aggregate reports; expanded generators, graders, author solutions and model traces remain private.

Historical visible-input dataset: https://huggingface.co/datasets/qingyuanwu/reconcile-workflow-lab/tree/06996df784f0a69bb46cc2992d5842992a8bd43e . That revision describes an earlier eight-domain design and is not relabeled as the latest experimental profile.

The admitted v1 pilot remains on the [main branch](https://github.com/QingyuanWuNothing/openenv-reconcile-lab/tree/main). Its private evaluation was 3/40 versus the base reference's 4/40; one small evaluation does not establish a systematic regression.

Release gates remain behavioral learnability, fresh selection and trained-versus-base checks, private-source hosting, and anonymous replay of the immutable expanded image. The exact final Arena request will be shown for fresh human approval before an official submission.
